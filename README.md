# 🛡️ Telegram Бот Цензуры, Антиспама и Антипорно

Универсальный бот для защиты комментариев канала [Voron Dolls](https://t.me/vorondolls) и любых других Telegram-каналов и групп от спама, порнографии, рекламы, скама и нежелательных сообщений.

---

## 📌 Как это работает в Telegram

1. **Комментарии в канале**: В Telegram комментарии под постами канала физически публикуются в **привязанной группе обсуждений** (Discussion Group). Бот добавляется в эту группу администратором с правами *«Удаление сообщений»* и *«Блокировка пользователей»*. Бот мгновенно удаляет нежелательные комментарии под любым постом.
2. **Личные сообщения («Написать каналу»)**: В описании канала можно указать ссылку на этого бота (например, для заказа кукол или вопросов). Бот отсекает весь спам, интим-ботов и рекламу в ЛС, а реальные сообщения клиентов отправляет администратору с удобной кнопкой **«💬 Ответить клиенту»**.
3. **Универсальность**: Бот хранит настройки раздельно для каждого чата в базе данных SQLite. Вы можете использовать одного и того же бота сразу в нескольких каналах и группах с индивидуальными настройками!

## ⚡ Функции модерации

- 🔞 **Анти-Порно / 18+**: Распознает интим-предложения, эскорт, адалт-ссылки, вебкам, онлифанс, сливы, в том числе с обходом (замена букв латиницей, цифрами, точками типа `с.е.к.с` или `п0рн0`). *При этом не блокирует обычные слова (например, слово «канал» не триггерит фильтр).*
- 🚫 **Анти-Спам / Скам**: Ловит рекламу заработка, криптовалют, ставок, «ищу моделей», «набираю команду», призывы перейти по ссылке в профиле и т.д.
- ⚡ **Анти-Флуд**: Защита от спам-атак (ограничение частоты сообщений от одного пользователя).
- 🔗 **Анти-Ссылки**: Удаление ссылок на внешние сайты и инвайтов в приватные каналы (`t.me/+...`). Поддерживает **Белый список** (можно разрешить официальные ссылки, например `t.me/vorondolls`, `vk.com` и т.д.).
- 🌐 **Фильтр чужих алфавитов**: Удаление арабской, персидской вязи и экзотических символов, которыми часто спамят рейдерские боты.
- 🤬 **Фильтр мата**: Распознает нецензурную брань с учетом маскировки, не затрагивая безопасные слова (например, «рублей», «оскорблять», «колебания»).
- 🧹 **Очистка служебных сообщений**: Удаляет уведомления «пользователь вступил в группу / покинул группу», чтобы комментарии оставались чистыми.
- 📷 **Контроль медиа**: Возможность запретить отправку медиафайлов (фото/видео/стикеры) для обычных пользователей.
- ⚔️ **Гибкие наказания**: На выбор:
  - `delete` — только тихое удаление (рекомендуется для комментариев)
  - `warn` — выдача предупреждений (по умолчанию после 3 варнов — мут на 24ч)
  - `mute_1h` — мут нарушителя на 1 час
  - `mute_24h` — мут нарушителя на 24 часа
  - `ban` — бан нарушителя навсегда
- 📊 **Логирование и статистика**: Отправка отчетов об удаленном спаме в специальный закрытый канал или ЛС админу.

## 🚀 Быстрый старт

### Шаг 1. Создание бота в Telegram
1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Задайте имя (например: `Voron Dolls Guard`) и юзернейм (например: `vorondolls_mod_bot`).
4. Скопируйте полученный **HTTP API Token** (вида `1234567890:ABCdefGhIJKlmnoPQRsTUVwxyZ`).

### Шаг 2. Настройка бота
Откройте файл `config.yaml` или `.env` в папке проекта и укажите:
```yaml
BOT_TOKEN: "ВАШ_ТОКЕН_ОТ_BOTFATHER"
ADMIN_IDS:
  - 123456789  # Ваш Telegram ID (узнать можно у @userinfobot)
LOG_CHAT_ID: 0 # (Опционально) ID канала для логов удаленного спама
```

### Шаг 3. Подключение к каналу Voron Dolls
1. Зайдите в настройки вашего Telegram-канала `t.me/vorondolls` -> **Управление каналом** -> **Обсуждение** (проверьте, какая группа привязана для комментариев).
2. Зайдите в эту группу обсуждений и добавьте вашего созданного бота в участники.
3. Назначьте бота **Администратором группы** со следующими правами:
   - ✅ Удаление сообщений (Delete Messages)
   - ✅ Блокировка пользователей (Ban Users)
4. *(Опционально)* Можно также добавить бота администратором в сам канал с правом публикации/удаления.

### Шаг 4. Запуск бота
- **Windows**: Просто дважды кликните по файлу `run.bat`
- **Командная строка / Linux**:
  ```bash
  python main.py
  ```

## 🛠️ Управление и команды администратора

В чате комментариев или в личных сообщениях с ботом доступны команды:

| Команда | Описание |
|---|---|
| `/settings` или `/panel` | Открыть интерактивную панель с кнопками для включения/выключения фильтров |
| `/addword [слово]` | Добавить слово в черный список текущего чата |
| `/delword [слово]` | Удалить слово из черного списка |
| `/words` | Посмотреть текущий черный список чата |
| `/addwhitelist [домен]` | Разрешить ссылку/домен (например `/addwhitelist t.me/vorondolls` или `/addwhitelist vk.com`) |
| `/delwhitelist [домен]` | Удалить из белого списка |
| `/whitelist` | Список разрешенных ссылок |
| `/stats` | Статистика удаленного спама по категориям |
| `/mute [минут]` | Замутить пользователя (ответом на его сообщение) |
| `/unmute` | Снять ограничения с пользователя |
| `/ban` | Заблокировать нарушителя (ответом на сообщение) |
| `/help` | Справка по всем функциям |

## 🎛️ Интерактивная панель `/settings`

При вводе `/settings` администратор видит удобные кнопки переключения:
```text
[ 🔞 Порно: ВКЛ ✅ ]   [ 🚫 Спам: ВКЛ ✅ ]
[ ⚡ Флуд: ВКЛ ✅ ]    [ 🔗 Ссылки: ВКЛ ✅ ]
[ 🌐 Спам-шрифт: ВКЛ ✅ ] [ 🤬 Мат: ВКЛ ✅ ]
[ 🧹 Служебные: ВКЛ ✅ ]  [ 📷 Запрет медиа: ВЫКЛ ❌ ]
[ 🤫 Тихий режим: ВКЛ ✅ ][ ⚔ Наказание: DELETE ]
[ 📊 Статистика ]      [ 📝 Стоп-слова ]
```
Каждый переключатель сохраняется в базу данных `bot_data.sqlite3` индивидуально для каждого чата.

## 📦 Структура проекта

```text
├── bot/
│   ├── config.py           # Конфигурация (.env и config.yaml)
│   ├── database.py         # SQLite БД (настройки чатов, стоп-слова, логи)
│   ├── filters/
│   │   ├── word_lists.py   # Базы слов, нормализация, регулярные выражения
│   │   └── moderator.py    # Ядро фильтрации сообщений и ссылок
│   └── handlers/
│       ├── admin.py        # Панель /settings, управление стоп-словами, бан/мут
│       ├── group_moderation.py # Модерация комментариев и групп
│       └── private_dialog.py   # Фильтрация входящих обращений к каналу в ЛС
├── config.yaml             # Главный файл настроек
├── .env.example            # Пример переменных окружения
├── requirements.txt        # Зависимости Python (aiogram 3, aiosqlite, pydantic)
├── run.bat                 # Быстрый запуск для Windows
├── test_filters.py         # Набор автотестов фильтрации
└── main.py                 # Точка входа
```
